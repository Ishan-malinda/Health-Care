Home Page

Technical Description

The home page of a health-focused website that provides users with trustworthy health and wellness information is represented by this HTML document. Key components of the website are easily accessible thanks to the page's navigation bar, which includes links to categories including Home, Table, Team, Volunteer, User Profile, and Feedback. The website's hero section and mission statement, which emphasises the site's dedication to empowering people with health-related knowledge, are presented in the main content area. To give consumers more information, four content tiles below link to particular subjects including physical fitness, mental health, nutrition, and healthy living choices. Links to social networking, website navigation, and other helpful resources like terms of service and privacy policies are all included in the footer.The layout is responsive to guarantee mobile device compatibility and is organised for accessibility, including alt text for photos. The website's goal of educating and assisting the public in leading healthy lives is promoted by its well-structured design, which also makes user interaction easier.

Accessibility

In this webpage, accessibility has been addressed by ensuring a clear and consistent navigation structure, providing descriptive <alt> text for images to assist screen readers, and using semantic HTML elements like <nav>, <header>, <main>, <section>, and <footer> for better readability by assistive technologies. The text has sufficient contrast against the background to enhance readability, and links are clearly labeled to provide meaningful navigation. Additionally, the page follows a logical structure to support keyboard navigation, making it accessible to users with disabilities.

Content Page

Technical Description

Content Page is built using <html> and <body> elements. The content is structured within a <main> section containing multiple <div> elements for organizing text and images. The main heading is wrapped in <h1>, and each content section is divided into <div class="section">. Inside these sections, text is placed within <div class="text"> and images within <div class="image">, with additional classes for styling. The footer includes <footer>, with author info inside <p> and a link in <a>.

Accessibility

page implements key accessibility features. The images use alt attributes (e.g., <img src="Images/5.png" alt="Healthy Food">) to provide descriptive text for screen readers. Proper semantic HTML tags, such as <h1> for the main heading and <p> for paragraphs, help structure the page for assistive technologies. Text and images are organized within clear, accessible <div> containers, ensuring that users with screen readers can navigate and understand the content easily. The footer also uses clear labeling with <a> for links and <p> for author information, promoting full accessibility.
