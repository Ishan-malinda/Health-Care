Feedback

Technical Description

This feedback form is structured using HTML5 and styled with CSS3, ensuring a user-friendly and responsive design. The form uses <form> with the post method for secure data handling, and input fields like <input type="text">, <input type="email">, and <textarea> for user responses. Radio buttons (<input type="radio">) and a <select> dropdown allow for multiple-choice feedback. The form also includes a star rating system using <input type="radio "> and <label> for accessibility. CSS is used for layout, typography, and responsiveness, enhancing usability with structured labels, placeholders, and clear visual feedback elements.

Accessibility

This feedback form incorporates accessibility best practices by using <label> elements linked to form fields for better screen reader support. Required fields are clearly indicated, and radio buttons and the star rating system are properly labeled for easy navigation. Placeholder text provides guidance, while semantic HTML elements like <main> and <footer> improve structure. The form also ensures keyboard accessibility, allowing users to navigate and submit responses without a mouse.

Team Page

Technical Description

This page is structured using <html> and <body> elements, ensuring a well-defined document layout. The <main> section contains a <div class="container"> that holds the team details. Each team member is represented within a <div class="student">, which includes an <img> tag for their photo, a <div class="name"> displaying their name, and a <div class="details"> listing their role and contributions. CSS is used to enable a hover effect on the images, revealing additional details. The <footer> provides author information and a navigation link, ensuring proper structure and easy access to additional pages.

Accessibility

This page incorporates accessibility best practices by using alt attributes in <img> tags, allowing screen readers to describe images. Semantic HTML elements such as <main> and <footer> enhance readability for assistive technologies. Proper text hierarchy with <h1> and <h2> ensures clear navigation. The hover effect is designed to work without requiring precise cursor movement, improving usability for those with motor impairments. Additionally, adequate color contrast and spacing improve readability for users with visual impairments.

Content Page

Technical Description

Content Page is built using <html> and <body> elements. The content is structured within a <main> section containing multiple <div> elements for organizing text and images. The main heading is wrapped in <h1>, and each content section is divided into <div class="section">. Inside these sections, text is placed within <div class="text"> and images within <div class="image">, with additional classes for styling. The footer includes <footer>, with author info inside <p> and a link in <a>.

Accessibility

page implements key accessibility features. The images use alt attributes (e.g., <img src="Images/5.png" alt="Healthy Food">) to provide descriptive text for screen readers. Proper semantic HTML tags, such as <h1> for the main heading and <p> for paragraphs, help structure the page for assistive technologies. Text and images are organized within clear, accessible <div> containers, ensuring that users with screen readers can navigate and understand the content easily. The footer also uses clear labeling with <a> for links and <p> for author information, promoting full accessibility.

Challenges and Lessons Learned

Creation of this webpage presented key lessons on team work, solving problems, and acquiring new knowledge. Working in collaboration with my team made me appreciate collaborating since we shared ideas and supported each other as the page developed. I further had to acquire new knowledge, specifically in issues such as responsiveness and accessibility that played a major role in designing the page so it could be accessed by any user. Problem-solving was also necessary when we had problems with layout changes and image placement, but by trial and error and working around the problems, we were able to overcome them and improve the functionality and appearance of the webpage.

Compliance

The provided pages follow Janet guidelines by ensuring accessibility, usability, and technical standards. I included alt text for images, used proper HTML structure, and followed semantic tagging for better accessibility. The pages are also made mobile-friendly and easy to use according to Janet's usability standards. I followed coding best practices to ensure the pages work as well on different browsers as possible and are technically sound. In general, the web pages are Janet compliant for accessibility and functionality.
