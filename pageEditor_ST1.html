Splash Page

Technical Description

The splash screen covers the full viewport using width: 100% and height: 100vh, with a background image set to cover and a semi-transparent overlay for readability. Content is centered using Flexbox, while a spinning loader animation is created with @keyframes spin. The tag redirects users to home.html after four seconds for a smooth transition.

Accessibility

The Volunteer page is accessible with semantic HTML elements like section, h2, and p, ensuring screen reader compatibility. High-contrast colors enhance readability, while alt attributes describe images for visually impaired users. The dropdown menu and buttons are keyboard-navigable, and the scrollable section ensures easy content navigation.

Content Page

Technical Description

The page uses semantic HTML elements for structure and Flexbox for responsive layout. Key styles ensure readability with high-contrast colors and proper spacing. Images are responsive, and alt attributes enhance accessibility, making the design user-friendly and mobile-friendly.

Accessibility

Accessibility is addressed with semantic HTML for structure, descriptive alt attributes for images, high-contrast text for readability, and keyboard-navigable elements. Proper heading usage ensures a clear content hierarchy, improving accessibility for all users.

Challenges and Lessons Learned

A challenge was making the layout responsive across devices, which was solved using Flexbox and responsive images. Ensuring accessibility with proper alt attributes and a clear heading structure was another challenge, addressed through careful review. The key lesson was the importance of testing across devices and accessibility tools for a user-friendly experience.

Compliance

The pages comply with Janet regulations by using semantic HTML for accessibility, including alt attributes for images, and ensuring high contrast for readability. The design is responsive, ensuring compatibility across devices. These practices meet accessibility and usability standards, creating an inclusive web experience.
